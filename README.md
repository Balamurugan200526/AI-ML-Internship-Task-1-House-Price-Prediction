# 🏡 House Price Prediction Using Linear Regression

### AI & ML Internship – Task 1

A Machine Learning project that predicts house values using **Linear Regression** and the California Housing Dataset.

---

## 📌 Project Overview

The objective of this project is to build, train, and evaluate a Linear Regression model to predict house prices based on different housing-related features.

This project demonstrates the fundamental Machine Learning workflow, including data loading, Exploratory Data Analysis (EDA), visualization, model training, prediction, and performance evaluation.

## 🎯 Objectives

- Understand the fundamentals of Linear Regression.
- Load and explore the California Housing Dataset.
- Perform Exploratory Data Analysis.
- Visualize feature distributions and correlations.
- Train a Linear Regression model.
- Evaluate model performance using standard metrics.

## 📊 Dataset Information

**Dataset:** California Housing Dataset

- Total Records: 20,640
- Total Columns: 9
- Input Features: 8
- Target Variable: `MedHouseVal`
- Missing Values: 0

The dataset contains housing-related information used to predict median house values.

## ⚙️ Project Workflow

1. Import required Python libraries.
2. Load the California Housing Dataset.
3. Perform dataset exploration and statistical analysis.
4. Check missing values.
5. Visualize feature distributions using histograms.
6. Analyze feature relationships using a correlation heatmap.
7. Split the dataset into training (80%) and testing (20%) sets.
8. Train the Linear Regression model.
9. Generate predictions.
10. Evaluate model performance.
11. Visualize actual vs. predicted values.
12. Analyze residuals.
13. Save the trained model using Pickle.

## 📈 Model Evaluation

The model was evaluated using three performance metrics.

| Evaluation Metric | Result |
|---|---:|
| Mean Absolute Error (MAE) | 0.5332 |
| Root Mean Squared Error (RMSE) | 0.7456 |
| R² Score | 0.5758 |
